# CoreStoreCRM - Система управления обращениями клиентов

## Описание
CoreStoreCRM - это полнофункциональная система управления отношениями с клиентами (CRM), разработанная на C# с использованием WinForms и .NET 8. Система позволяет управлять обращениями клиентов, сообщениями, профилями пользователей и заказами.

## Функциональность

### Для клиентов:
- Регистрация и вход в систему
- Просмотр собственного профиля
- Создание новых обращений
- Просмотр статуса обращений
- Обмен сообщениями с менеджерами
- Просмотр истории заказов

### Для менеджеров:
- Просмотр всех обращений
- Управление обращениями (назначение, закрытие)
- Отправка ответных сообщений клиентам
- Просмотр информации о клиентах

### Для администраторов:
- Все функции менеджера
- Просмотр отчетов о закрытых обращениях
- Управление пользователями

## Требования

- .NET 8.0 или выше
- MySQL/MariaDB база данных
- Windows 7 или выше

## Установка

### 1. Подготовка базы данных

1. Откройте phpMyAdmin или другой инструмент управления MySQL
2. Создайте базу данных `corestorecrm`
3. Импортируйте дамп БД из файла `corestorecrm (6).txt`

### 2. Конфигурация строки подключения

Откройте файл `CoreStoreCRM/DataAccess/DatabaseHelper.cs` и обновите строку подключения:

```csharp
private static readonly string ConnectionString = "Server=YOUR_SERVER;Database=corestorecrm;Uid=YOUR_USER;Pwd=YOUR_PASSWORD;";
```

### 3. Установка зависимостей

```bash
cd CoreStoreCRM
dotnet restore
```

### 4. Сборка проекта

```bash
dotnet build
```

### 5. Запуск приложения

```bash
dotnet run
```

## Базы данных таблицы

- **product** - Товары
