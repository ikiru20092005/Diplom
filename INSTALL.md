## ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ

### Шаг 1: Подготовка базы данных

1. Убедитесь, что установлены MySQL/MariaDB (версия 10.4+)
2. Откройте phpMyAdmin (или командную строку MySQL)
3. Создайте базу данных:
   ```sql
   CREATE DATABASE corestorecrm;
   ```
4. Импортируйте SQL дамп:
   - Откройте файл `corestorecrm (6).txt` в текстовом редакторе
   - Скопируйте весь текст
   - Вставьте в phpMyAdmin -> вкладка SQL -> Вставить
   - ИЛИ через командную строку:
	 ```bash
	 mysql -u root -p corestorecrm < "corestorecrm (6).txt"
	 ```

### Шаг 2: Настройка проекта

1. Откройте файл `CoreStoreCRM\DataAccess\DatabaseHelper.cs`
2. Найдите строку подключения:
   ```csharp
   private static readonly string ConnectionString = "Server=127.0.0.1;Database=corestorecrm;Uid=root;Pwd=;";
   ```
3. Измените параметры:
   - **Server** - IP адрес MySQL сервера (по умолчанию 127.0.0.1 для локального)
   - **Uid** - имя пользователя БД (по умолчанию root)
   - **Pwd** - пароль БД (оставить пустым если нет пароля)

### Шаг 3: Установка зависимостей

Откройте PowerShell в папке проекта и выполните:

```powershell
cd E:\CoreStoreCRM\
dotnet restore
```

### Шаг 4: Сборка проекта

```powershell
dotnet build -c Release
```

### Шаг 5: Запуск приложения

```powershell

```

Или откройте проект в Visual Studio и нажмите F5 (Debug) или Ctrl+F5 (Release)

## РЕШЕНИЕ ПРОБЛЕМ

### Ошибка: "Не удается подключиться к базе данных"
- Проверьте, что MySQL сервер запущен
- Проверьте правильность параметров подключения в DatabaseHelper.cs
- Убедитесь, что база данных `corestorecrm` существует

### Ошибка: "Таблица не найдена"
- Убедитесь, что дамп БД был правильно импортирован
- Проверьте, что выбрана правильная база данных в phpMyAdmin

### Ошибка при запуске: "Неправильная версия .NET"
- Установите .NET 8.0 Runtime и SDK отсюда: https://dotnet.microsoft.com/download

### Приложение зависает при загрузке
- Проверьте скорость соединения с БД
- Убедитесь, что MySQL сервер полностью запущен

## СИСТЕМНЫЕ ТРЕБОВАНИЯ

- ОС: Windows 7 SP1 или выше
- .NET: 8.0 Runtime
- RAM: минимум 512 МБ
- Место на диске: 100 МБ
- БД: MySQL 5.7 или MariaDB 10.4+
