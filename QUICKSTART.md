## ⚠️ Если не работает

### MySQL не запускается?
```bash
# Проверьте статус
mysql -u root -e "SELECT 1;"

# Если ошибка - установите MySQL: https://www.mysql.com/downloads/
```

### Приложение не запускается?
```bash
# Восстановите пакеты
dotnet clean
dotnet restore
dotnet build
dotnet run
```

### "Неправильный email или пароль"?
```bash
# Проверьте БД
mysql -u root -e "SELECT email FROM corestorecrm.user;"

# Должны быть: ivan@mail.com, manager@mail.com, admin@mail.com
```
