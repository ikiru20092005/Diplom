## 🐛 Исправления в версии 1.1

### Главное исправление: Авторизация
**Проблема:** Пароли в БД хешированы BCrypt, код использовал SHA256
**Решение:** 
- Добавлена поддержка BCrypt
- Переработана логика проверки пароля
- Пароль теперь передается в открытом виде, хеширование происходит при сравнении

**Файлы изменены:**
- `PasswordHelper.cs` - перестроена логика хеширования
- `UserRepository.cs` - изменен способ проверки пароля
- `LoginForm.cs` - убрано предварительное хеширование
- `CoreStoreCRM.csproj` - добавлена зависимость BCrypt
- `DatabaseHelper.cs` - обновлена строка подключения

## 🎓 Дополнительная информация

### Расширение функциональности

Для добавления новых функций:

1. **Новая сущность в БД:**
   - Добавьте таблицу в SQL
   - Создайте Model класс в `Models/`
   - Создайте Repository в `DataAccess/`

2. **Новая форма:**
   - Создайте `Forms/NewForm.cs`
   - Создайте `Forms/NewForm.Designer.cs`
   - Добавьте кнопку в `MainForm.cs`

3. **Новая роль/права:**
   - Добавьте роль в таблицу `role`
   - Обновите проверку в `SessionManager.cs`
   - Обновите видимость кнопок в `MainForm.cs`

### Миграция на продакшн

1. Измените строку подключения на реальный хост
2. Включите SSL для подключения
3. Смените пароли администратора
4. Создайте резервные копии БД
5. Протестируйте на production сервере
