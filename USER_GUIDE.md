## Подробное описание функций

### Обращения (Appeals)

**Для клиента:**
- **Создать** - нажмите кнопку "Создать" и выберите тип обращения
- **Типы:** Вопрос, Проблема, Техническая поддержка
- **Просмотр** - список всех ваших обращений
- **Статусы:** Новое, В работе, Закрыто

**Для менеджера:**
- Видит все обращения
- Может назначить себя на обращение
- Может закрыть обращение
- Может отправить сообщение

**Сетка обращений показывает:**
- ID - номер обращения
- Клиент - имя клиента
- Тип - категория обращения
- Статус - текущий статус
- Менеджер - ответственный (для менеджеров)
- Дата создания

### Сообщения (Messages)

1. Выберите обращение из сетки
2. Нажмите "Просмотреть"
3. Справа появится список сообщений
4. Формат: `[Роль] Дата Время: Текст`
5. Введите сообщение в текстовое поле
6. Нажмите "Отправить"

**Пример:**
```
[Клиент] 2024-12-15 14:30: Здравствуйте, у меня проблема с заказом
[Менеджер] 2024-12-15 14:35: Добрый день! Какая именно проблема?
```

### Профиль пользователя

1. Нажмите кнопку "Профиль"
2. Отредактируйте данные:
   - ФИО
   - Email
   - Телефон
3. Нажмите "Сохранить" или "Отмена"

### Заказы

1. Нажмите кнопку "Заказы"
2. Просмотрите таблицу с вашими заказами
3. Информация включает:
   - ID заказа
   - Дату начала
   - Сумму
   - Статус
   - Адрес доставки
4. Кнопка "Обновить" для перезагрузки

### Администрирование

**Вкладка "Отчеты":**
- Список всех закрытых обращений
- Информация о клиенте
- Дата создания и закрытия
- Тип обращения
- Кнопка "Обновить"
- Кнопка "Экспорт" (в разработке)

**Вкладка "Пользователи":**
- Список зарегистрированных пользователей
- В разработке: фильтрация и управление

## Часто задаваемые вопросы

### Q: Как создать новое обращение?
A: Нажмите "Обращения" → "Создать" → Выберите тип → Введите описание → "Создать"

### Q: Как отправить сообщение менеджеру?
A: Откройте обращение → Введите текст → "Отправить"

### Q: Как закрыть обращение?
A: Выберите обращение → нажмите "Закрыть" (если вы менеджер или администратор)

### Q: Как изменить свой профиль?
A: Нажмите "Профиль" → отредактируйте данные → "Сохранить"

### Q: Где посмотреть отчеты?
A: Только администратор может видеть отчеты (кнопка "Администрация")

### Q: Почему я не вижу все обращения?
A: Клиенты видят только свои обращения. Менеджеры видят все.

- **F5** или **Обновить** - перезагрузить данные
- **Escape** - закрыть окно формы
- **Enter** - отправить форму

## Проблемы и решения

### "Не удалось подключиться к БД"
1. Проверьте, что MySQL запущен
2. Проверьте строку подключения

### "Ошибка при загрузке обращений"
1. Попробуйте нажать "Обновить"
2. Убедитесь, что база данных работает

### "Сообщение не отправилось"
1. Проверьте, что обращение выбрано
2. Убедитесь, что сообщение не пусто
3. Проверьте подключение к БД
