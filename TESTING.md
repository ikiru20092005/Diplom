# Быстрый тест авторизации

## Шаг 1: Проверка БД

Выполните SQL запрос в phpMyAdmin:

```sql
SELECT userId, email, name, roleId FROM user LIMIT 5;
```

Вы должны увидеть:
- userId: 1, email: ivan@mail.com (роль 1 = клиент)
- userId: 3, email: manager@mail.com (роль 2 = менеджер)
- userId: 4, email: admin@mail.com (роль 3 = администратор)

## Шаг 2: Проверка хешей паролей

```sql
SELECT email, passwordHash FROM user;
```

Все хеши должны начинаться с `$2a$` или `$2b$` или `$2y$` (это формат BCrypt).

## Шаг 3: Тестирование приложения

1. Запустите приложение: `dotnet run`
2. В окне LoginForm будут предзаполнены данные:
   - Email: ivan@mail.com
   - Пароль: password
3. Нажмите кнопку "Вход"
4. Вы должны войти в главное меню

## Шаг 4: Проверка ролей

### Если вы вошли как КЛИЕНТ (ivan@mail.com):
- Видите кнопки: "Обращения", "Профиль", "Заказы", "Выход"
- Кнопка "Администрация" скрыта ✓

### Если вы вошли как МЕНЕДЖЕР (manager@mail.com):
- Видите кнопки: "Обращения", "Профиль", "Заказы", "Выход"
- Кнопка "Администрация" скрыта ✓

### Если вы вошли как АДМИНИСТРАТОР (admin@mail.com):
- Видите кнопки: "Обращения", "Профиль", "Заказы", "Администрация", "Выход"
- Кнопка "Администрация" видна ✓

## Шаг 5: Проверка обращений

### Для клиента:
1. Нажмите "Обращения"
2. Вы увидите список ваших обращений
3. Кнопка "Создать" должна быть активна

### Для менеджера:
1. Нажмите "Обращения"
2. Вы увидите ВСЕ обращения (от всех клиентов)
3. Кнопка "Создать" должна быть неактивна

## Возможные проблемы и решения

### Проблема: "Не удается подключиться к базе данных"
**Решение:**
1. Проверьте, что MySQL запущен
2. Проверьте строку подключения в DatabaseHelper.cs
3. Убедитесь, что база данных `corestorecrm` существует

```bash
# Проверить БД из командной строки:
mysql -u root -e "SHOW DATABASES LIKE 'corestorecrm';"
```

### Проблема: "Неправильный email или пароль" при вводе правильных данных
**Решение:**
1. Проверьте, что хеши в БД начинаются с $2a$, $2b$ или $2y$
2. Убедитесь, что пакет BCrypt.Net-Next установлен
3. Пересоберите проект: `dotnet clean` и `dotnet build`

### Проблема: При входе выбрасывает исключение
**Решение:**
1. Посмотрите сообщение об ошибке
2. Проверьте логи MySQL: `/var/log/mysql/error.log`
3. Попробуйте пересоздать дамп БД
